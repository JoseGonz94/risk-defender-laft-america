# Risk Defender Web App v23

Versión universal para el evento.

- iPhone/iPad: oculta fullscreen y usa el viewport real de Safari/Chrome.
- Safari: la pantalla inicial se escala automáticamente para que alias e INICIAR MISIÓN queden visibles.
- Android/PC/navegadores compatibles: conserva Fullscreen API real.
- Se retiró el service worker para evitar que Chrome/iOS conserve versiones antiguas durante las pruebas.
- No requiere instalación.
- Disparo y flechas conservan el mismo tamaño aprobado.

Sube los archivos de esta carpeta a la raíz del repositorio.
